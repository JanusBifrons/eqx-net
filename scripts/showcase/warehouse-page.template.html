Warehouse Bases

Endless storage yards generated from a single seed. The server, every player's physics prediction and the renderer all rebuild the same yard from about 60 bytes of description, so nothing heavy crosses the network.

Seed 42 · 8000 u footprint · generator v3 · drawn with the same draw plan as the in-game renderer

In the game

In-game stills are from the build just before the density pass; the clip above is the current layout.

What works now

  • Walls and racks block ships on the server and in each player's prediction, from identical geometry.
  • Lasers and bolts stop at base walls.
  • Ships slide along walls without snagging on the joins between pieces.
  • Fast ships, drones and debris can't tunnel through thin walls.
  • Spawns asked for inside a wall are moved to the nearest open space.
  • Each player loads only the walls near their ship.

How it is built

  • Loading bays at 2–4 gates, lined with container stacks.
  • Double-depth rack rows all running one way, with cross-aisles.
  • A repair pass opens any pocket a ship could see but never enter.
  • Every corridor is at least 160 u wide, 6× the largest flyable ship's radius.
